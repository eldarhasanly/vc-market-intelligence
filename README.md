# VC Market Intelligence: Venture Capital in the Post-GPT Era

An end-to-end data analytics and Power BI project examining changes in venture capital markets following the emergence of GenAI, with a dedicated deep dive into the EdTech sector.

## Project Status

🚧 In development

Current stage: Data acquisition and pipeline development.

## Objectives

This project will investigate:

- Global VC trends before and after the emergence of ChatGPT
- Changes in funding volumes, deal activity, and deal sizes
- The growing role of AI and GenAI in venture investment
- Capital concentration and mega-round activity
- Geographic and funding-stage differences
- VC trends within the EdTech sector
